## 2. 迭代建议规则

| 症状 | 可能原因 | 迭代动作 | 对应管线 |
|---|---|---|---|
| 点击率低于类目均值 | 主图不抓眼 / 标题前三字无钩子 | 换主图（换角度/加徽章）；标题前三字放核心利益点 | layout.py（jd_main 徽章 / amazon_extra 场景） |
| 转化率低、加购率高 | 卖点顺序不对 / 缺场景证据 | 痛点型卖点前置；补场景图/对比表 | plan.py（重排图位用途）→ copy.py → layout.py |
| 转化率低、停留短 | 信息过载或缺关键参数 | 砍文案到 4 条以内；参数表前置 | copy.py / amazon_extra_2 |
| 退货集中在某一原因 | 参数与实物不符 / 预期管理缺失 | 核对官网 Specifications；详情页加警示说明 | ops-checklist.md 文案终审 |
| 差评关键词集中 | 文案承诺过度 / 图片误导 | 降级承诺性表述；换更写实的产品图 | copy.py + Tier 0 实拍 |
| 季节性波动 | 节日已过 / 季节不符 | 切换季节海报主题 | seasons.py → layout.py season_poster |

**铁律**：一次只改一个变量（换主图就别同时改标题），改后观察 ≥7 天再下结论；
每次迭代更新 plan.md 的版本号并归档旧版。

## 3. 复盘 Checklist

- [ ] 数据已填入 §1 表格（曝光/点击/转化/退货/差评原词）
- [ ] 定位到 §2 规则表中的 1 个主症状（一次只解决一个）
- [ ] 迭代动作已明确到具体文件（图位/文案条目）
- [ ] 改后已跑 validate.py（尺寸/规范无回归）
- [ ] plan.md 版本号已递增，旧版已归档
- [ ] 7 天后回填数据，验证迭代效果
