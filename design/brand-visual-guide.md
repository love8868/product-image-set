## 1. MANHATTAN（manhattanproducts.eu）

**品牌色（实测）**
| 用途 | 色值 | 来源 |
|---|---|---|
| 品牌蓝 | `#017AC3` | 官网 trust badge 主色 |
| 标题深青蓝 | `#005485` | 充电柜 banner 主标题 |
| 背景白 | `#FFFFFF` | 全站底色 |
| 浅灰蓝（辅助背景） | `#F4F6F8` | 内容区分隔 |
| 墙面浅蓝（场景） | `#B8CEDC` | banner 场景墙面 |
| 强调橙 | `#E8730C`（目测，待精确采样） | logo 圆点弧、标题下划线，小面积点缀 |
| 正文深灰 | `#1F2933` | 全站正文 |

**字体气质**：标题用粗壮、略带圆润感的无衬线（亲和有力）；正文用干净的人文主义无衬线。
英文品牌标语："Life just got easier." —— 口语化、轻松。

**整体调性**：明亮、亲和、轻商务。面向教育 / 酒店 / 办公 / 家用场景，
讲"好用、省心"，不讲硬核参数。

**构图习惯（官网 banner 实测）**
- 浅色明亮展厅式场景，产品按真实比例一字排开
- 左上大标题（深青蓝）+ 一条橙色短下划线点缀 + 浅色副标题
- 留白充足（约 30%+），右下角放品牌 logo
- 产品图：白底实拍为主，细节图干净无干扰

## 2. INTELLINET（intellinetsolutions.com）

**品牌色（实测）**
| 用途 | 色值 | 来源 |
|---|---|---|
| 深海军蓝（背景） | `#022D5C` | 交换机 banner 背景 |
| 亮蓝（渐变） | `#0166AA` | banner 背景渐变 |
| 强调橙 | `#EB711F` | pill 徽章、分隔圆点、标题下划线 |
| 标题白 | `#FFFFFF` | banner 主标题 |
| 辅助浅灰 | `#8A93A4` | 次级文字 |

**字体气质**：标题用超粗无衬线（偏紧凑、有压迫感的力量感）；
数据 / 型号标注带技术感（等宽或紧凑无衬线），常用橙色 pill 胶囊承载"型号 / 参数"。

**整体调性**：深色科技、专业硬核。面向网络工程师、数据中心、系统集成商，
讲"性能、规格、可靠性"。

**构图习惯（官网 banner 实测）**
- 深海军蓝渐变底 + 对角光 streak（左上蓝光 / 右下橙光）
- 产品居中 hero 位，放在反光台面上，带倒影
- 左上白色粗标题 + 橙色短下划线；副标题列 3 个卖点，橙色圆点分隔
- 橙色 pill 徽章标注具体型号（如 "18-Port Model 562065"），放在产品右上 / 右下

## 3. 两品牌差异速览

| 维度 | MANHATTAN | INTELLINET |
|---|---|---|
| 主题 | 浅色（白 / 浅灰蓝） | 深色（海军蓝渐变） |
| 主色 | 品牌蓝 `#017AC3` | 深海军蓝 `#022D5C` |
| 标题色 | 深青蓝 `#005485` | 白 `#FFFFFF` |
| 强调橙用法 | 小面积点缀（logo、下划线） | 功能性标注（pill、分隔点） |
| 调性 | 亲和轻商务 | 专业硬核 |
| 典型场景 | 明亮展厅 / 办公室 | 深色机房 / 科技感 |
| 受众 | 教育、酒店、办公采购 | 网络工程师、集成商 |

共同点：同属 IC Intracom，蓝 + 橙的撞色语言是家族特征，只是明暗主题相反。

## 4. 视觉合同（STYLE LOCK）设计侧条目

套图生成时按品牌二选一注入，全局共享。

### 4.1 Manhattan 主题（浅色）

```
palette:
  background:  #FFFFFF（主） / #F4F6F8（辅助区分）
  text:        #1F2933
  primary:     #017AC3（品牌蓝：徽章、图标底、链接色）
  headline:    #005485（大标题）
  accent:      #E8730C（橙：仅点缀，≤10% 面积——下划线、徽章描边、小标签）
  deep:        #0A2A43（深色底，极少用，如页脚条）
tone: 中性偏冷，明亮通透
lighting: 柔和明亮的自然光 / 影棚柔光，产品下极淡自然阴影，无戏剧化暗角
composition: 对称稳定，大留白（≥30%），标题左上 + 橙色短下划线，产品按真实比例陈列
```

### 4.2 Intellinet 主题（深色）

```
palette:
  background:  linear-gradient(#022D5C → #0166AA)（深海军蓝渐变，允许对角光 streak）
  text:        #FFFFFF（主） / #8A93A4（次级）
  primary:     #0166AA（亮蓝：渐变、光效）
  accent:      #EB711F（橙：pill 徽章、分隔点、下划线、参数高亮）
tone: 冷，深色科技
lighting: 戏剧化边缘光 / rim light，产品带地面反射，背景有明暗层次
composition: 产品居中 hero，对角线引导（光 streak），橙色 pill 做型号/参数标注
```

### 4.3 字体系统

| 场景 | 英文推荐 | 中文推荐 | 说明 |
|---|---|---|---|
| 大标题 | 粗无衬线 800：Manhattan 偏圆润（如 Nunito ExtraBold 气质），Intellinet 偏紧凑黑体感（如 Barlow Condensed Bold 气质） | 思源黑体 Heavy / Bold | 商用授权需单独确认；当前管线临时用 Noto Sans CJK |
| 正文 / 卖点 | 人文主义无衬线 400/500 | 思源黑体 Regular / Medium | 同上 |
| 数据 / 型号标注 | 紧凑无衬线或等宽 600 | 思源黑体 Medium | Intellinet 场景常用橙色 pill 承载 |

> 注：以上为"气质描述 + 举例"，不等同于指定字体文件。最终字体待商用授权确认后锁定，
> 在此之前 layout.py 用系统可用字体（已验证 Noto Sans CJK 可用）按此层级实现。

### 4.4 通用铁律（两品牌共享）

1. 底色占比 ≥70%，主色 ~20%，强调橙 ≤10% —— 橙永远是配角，不铺底、不染产品
2. 产品本身不参与主题配色：节日 / 主题色只出现在背景与文字，产品区保持中性过渡
3. 文字对比度：浅底用深字（#1F2933 / #005485），深底用白字；文字压图时加 40–60% 黑色罩
4. 一套图内（同一产品）字体、字重层级、配色比例全程一致 —— 由 STYLE LOCK 全局注入保证
