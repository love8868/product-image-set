# 各图位版式设计规范（Layout Design Specs）

> 给 `layout.py` 的实现规格。所有尺寸参数均为**相对值**（占图宽 W / 图高 H 的百分比），
> 直接换算成像素即可。配色引用 `brand-visual-guide.md` 的主题变量，不写死 hex
> （Manhattan 浅色主题 / Intellinet 深色主题二选一）。
> 设计目标：信息清晰优先，克制、有层级；全部可用 Pillow 基础能力实现
> （矩形、渐变、文字、描边、半透明罩），不依赖 AI 生图技巧。

---

## 0. 通用规则（所有图位共享）

### 0.1 网格与安全区
- 安全区：四边各留 **5%**（W/H 中较小边的 5%），关键文字与产品主体不得出安全区
- 基准网格：正方形图 12 列，宽幅图 16 列；文字左对齐时起于第 2 列

### 0.2 字号体系（以图高 H 为基准）
| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| H1 主标题 | **8–10% H** | 800 | 核心结论，一眼可读 |
| H2 副标题 | **4–5% H** | 600 | 参数 / 补充说明 |
| Body 卖点 | **3–3.5% H** | 500（关键词 700） | 信息图条目 |
| Caption 标注 | **2.2–2.8% H** | 600 | pill 徽章、角标 |
| 最小字号 | 不低于 **2% H** | — | 低于此则删文案，不缩小 |

- 行距 1.25–1.4；中英文混排时中文用同级字号（中文视觉偏大，可降 5%）
- 标题不超过 2 行，单行不超过 12 个英文词 / 14 个汉字

### 0.3 配色用量
- 底色 ≥70%，主色 ~20%，强调橙 ≤10%（点缀：下划线、pill、icon 底）
- 浅底（Manhattan）：正文 `#1F2933`，大标题 `#005485`，卖点关键词品牌蓝 `#017AC3`
- 深底（Intellinet）：正文白 `#FFFFFF`，次级 `#8A93A4`，型号/参数用橙 pill（`#EB711F` 底 + 白字）

### 0.4 文字压图规则
- 文字不得直接压在产品主体上；必须压图时加 **40–60% 黑色渐变罩**（从文字区边缘向内羽化）
- 白字最小对比度：罩后文字与背景对比度 ≥ 4.5:1（目测：罩上字清晰无眩光即可）

### 0.5 产品占比
| 图位 | 产品占比（占画面） |
|---|---|
| Amazon / 京东主图（Tier 0） | ≥85%（平台合规红线），纯白底 |
| 附图场景图 | 45–65% |
| 信息图 | 35–50%（产品 + 信息并重） |
| banner / 海报 | 40–60%（产品可出画 bleed，但主体完整） |

## 1. amazon_extra_1 —— 场景图（2000×2000）

**信息架构**：结论先行（"一次充 10 台"），场景给证据。

**布局**：全幅场景底图；产品自然融入，占 50–60%，位于右下 2/3 区；
文字区在左上，宽 ≤55% W，高 ≤35% H，不与产品主体重叠。

**文字层级**：
- H1（9% H，800）：结论句，如 "Charge 10 Devices at Once."
  Manhattan：`#005485` + 下方一条橙色短下划线（宽 = 标题宽的 25%，高 0.6% H）
  Intellinet：白色 + 橙色短下划线
- H2（4.5% H，600）：参数句，如 "30W per port · USB-C PD"，颜色次级
- 不再加第三级文字

**配色**：场景底按品牌主题（Manhattan 明亮展厅 / Intellinet 深蓝科技）；
文字区如需可读性加轻微深色罩（Manhattan 用白罩 30%，Intellinet 用黑罩 50%）。

**简化规则**：无（2000px 足够）。

## 2. amazon_extra_2 —— 信息图（2000×2000）

**信息架构**：证据陈列（3–4 个卖点，一句话一条）。

**布局**：浅底（Manhattan `#F4F6F8` / Intellinet 深蓝渐变）；
左 45% 为产品（白底产品图直贴，四周留白 8%）；
右 55% 为卖点列表，垂直均分，每条之间间距 ≥4% H。

**单条卖点结构**（自上而下）：
- icon：直径 6% H 的圆，品牌蓝底（Manhattan `#017AC3`）/ 橙底（Intellinet `#EB711F`），白色线性图标
- 关键词（3.5% H，700，品牌蓝 / 白）+ 说明句（3% H，500，次级色），同一行或上下两行
- 条目示例："10× USB-C Ports —— 每口 30W，多设备同时满速充"

**顶部**：一条 H2 级小标题（4.5% H，700），如 "Why you'll love it" / "核心卖点"，
下方配 0.5% H 的分隔线（浅灰 / 半透明白）。

**简化规则**：卖点超过 4 条时只留 4 条，多余的进详情页；每条说明句不超过 20 字。

## 3. jd_main —— 京东主图（1200×1200）

**布局**：纯白底（`#FFFFFF`）；产品居中，占 70%；
顶部一条短标题（H2，4.5% H，700，`#1F2933` / 深底主题不用）；
底部 1–2 个卖点 pill 徽章横排居中。

**pill 徽章规格**：高 6% H，圆角 = 高的 50%，内边距左右各 3% W；
Manhattan：品牌蓝底 `#017AC3` 白字；Intellinet：橙底 `#EB711F` 白字；
文字 Caption 级（2.8% H，700），如 "30W 快充" / "10 口同充"。

**注意**：京东首图保持干净——标题 + 徽章总数不超过 3 个文字元素；
徽章不遮挡产品（产品区与徽章区垂直间距 ≥3% H）。

## 4. web_banner —— 官网首页大图（2000×440）

**布局**：左文右图。文字区占左 42% W（起于 6% W），垂直居中；
产品区占右 58% W，产品高度 90–100% H，允许右侧出画 bleed（主体完整）。

**文字层级**（H 以 440 为基准，字号按 0.2 节放大一级保证一眼可读）：
- H1（**17% H**，800）：不超过 8 个词，如 "Charge 10 Devices at Once."
  下方橙色短下划线（宽 18% W，高 1% H）
- H2（7% H，600）：一行参数，如 "30W per port · USB-C Power Delivery"
- 只保留这两级，不加卖点列表（440 高度下信息过载）

**背景**：品牌主题弱化版——Manhattan 用极浅灰蓝渐变（`#F4F6F8 → #E8EDF3`），
Intellinet 用深海军蓝横向渐变（`#022D5C → #01407E`）；可加极淡的对角光，
不抢产品与文字。

**小屏适配**：官网 banner 在小屏可能被裁剪——关键文字与产品主体放在
**中央 60% W** 安全区内，两侧 20% 只放背景延续。

## 5. mobile —— 手机端（1000×900）

**布局**：上下结构。上 38% H 为文字区（居中），下 62% H 为产品区；
产品占 55–65%，居中，下方留白 5%。

**文字层级**（手机观看距离近，字号放大一级）：
- H1（10% H，800，居中）：结论句，不超过 10 个字 / 6 个词
- H2（5% H，600，居中）：一行参数
- 可选 1 个 pill 徽章（同 jd_main 规格，放大到 7% H）

**注意**：拇指区——产品要大，文字要少；背景用纯色或极淡渐变，
避免复杂场景在小图上糊成一团。

## 6. season_poster —— 季节海报（1080×1440，3:4）

**布局**：上中下三段。
- 上 28% H：标题区。节日氛围背景 + H1（9% H，800）节日主标题，
  如 "圣诞季 · 一站式充电" / "Christmas Power Hub"；可配小字 H2（4% H）副标题
- 中 47% H：产品 hero 区。**中性过渡背景**（浅灰 `#F4F6F8` / 深灰渐变），
  产品占本区 70%，居中。产品区不受节日色污染
- 下 25% H：行动区。2–3 条卖点（Body 级，居中或左对齐）+ 可选促销 pill
  （如 "限时 9 折"，橙底白字，Caption 级加粗）

**节日配色**（只用于标题区与行动区点缀，产品区保持中性）：
| 节日 | 标题区配色 | 点缀 |
|---|---|---|
| 圣诞 Christmas | 深绿 `#0F4D2E` → 墨绿渐变 | 金 `#C9A227` 星光点、红 `#C0392B` 小面积 |
| 春季 Spring | 浅粉绿 `#E8F5E9 → #C8E6C9` | 嫩绿 `#7CB342` |
| 夏季 Summer | 天蓝 `#E1F5FE → #B3E5FC` | 亮蓝 `#039BE5` |
| 秋季 Autumn | 暖米 `#FFF8E1 → #FFECB3` | 赭石 `#E65100`（小面积） |
| 万圣节 Halloween | 深紫 `#2A1A4E` | 橙 `#EB711F`（呼应品牌橙） |
| 黑五 Black Friday | 纯黑 `#0A0A0A` | 金 `#C9A227` / 品牌橙 |
| 新年 New Year | 深蓝 `#0A1E3C` | 金 `#C9A227` |
| 情人节 Valentine | 淡粉 `#FCE4EC` | 玫红 `#D81B60`（小面积） |

**铁律**：节日色只做氛围，产品本身的颜色、外观不受任何节日滤镜影响；
中性产品区与节日标题区之间用 3% H 的渐变过渡带衔接，不硬切。

## 7. 给 layout.py 的实现参数表

| 参数 | 取值 | 说明 |
|---|---|---|
| `SAFE = 0.05` | 安全区（相对短边） | |
| `TYPE_SCALE = {h1: 0.09, h2: 0.045, body: 0.032, cap: 0.026}` | 字号/图高（banner/mobile 按各节标注覆盖） | |
| `LINE_H = 1.3` | 行距倍数 | |
| `SCRIM = 0.5` | 文字压图罩不透明度 | 黑罩；Manhattan 浅底场景可用白罩 0.3 |
| `ACCENT_MAX = 0.10` | 强调橙最大面积比 | |
| `PILL_R = 0.5` | pill 圆角 = 高 × 0.5 | |
| `PRODUCT_MAIN_MIN = 0.85` | 主图产品最小占比（合规） | |
| `THEMES = {manhattan: {...}, intellinet: {...}}` | 见 brand-visual-guide.md §4 | 主题变量表 |

**实现顺序建议**：先实现 Manhattan 浅色主题（MVP 产品是 Manhattan 充电柜），
Intellinet 深色主题作为第二套主题参数接入，版式结构复用。

## 8. 验收自查（设计侧，美工目检用）

- [ ] 同一产品整套图：字体层级、配色比例、橙色用量一致
- [ ] 标题 2 米外可读（banner / 海报按 50% 缩放预览检查）
- [ ] 文字无压产品主体；压图处有罩且对比度足
- [ ] 橙色只出现在点缀位（下划线/pill/icon），无大面积橙底
- [ ] 季节海报：产品区中性，无节日色污染
- [ ] 小尺寸图（mobile/jd_main）文字不超过 3 个元素
